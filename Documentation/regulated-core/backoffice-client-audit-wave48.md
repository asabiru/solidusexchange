# Backoffice Client Audit — Wave 48 — Proposed

- Status: Proposed
- Scope: `backoffice/src/app/**` (App.tsx views/detail panes, i18n, runtime, icons, navigation), `backoffice/src/data/client.ts` (envelope verification + API consumers), `backoffice/src/data/demo.ts`/`provider-evidence.ts`/`reports.ts` payload shapes — the operator-side mirror of the wave-40 miniapp audit
- Production effect: none

## Scope reviewed

- Every React consumer of server payloads in `backoffice/src/app/App.tsx` (~30 views, detail panes, shared list widgets, the maker-checker preview and step-up flow, the subject-360 timeline, report tables and the audit export panel).
- Formatting/i18n helpers: `backoffice/src/app/i18n.ts`, `i18n-context.tsx`.
- Client trust boundary: `backoffice/src/data/client.ts` (`verifyEnvelope`, `ApiError`, request builders), `runtime.ts`.
- Static configuration: `navigation.ts`, `icons.tsx`, `auth/access.ts` capability checks.

Hunt list applied (same classes as the wave-40 miniapp audit): foreign enum/status values reaching `map[value]`/`lookup[value].tone` access, prototype keys (`"toString"`, `"constructor"`, `"__proto__"`) bypassing object-member guards, non-array collections reaching `.map`/`.filter`/`.length`, NaN/Infinity/timestamp abuse, missing nested fields on record chains, money/decimal display, the client-side envelope verifier treating unverified content as verified, and operator/provider-supplied strings interpolated into hrefs/markup.

## Defects found and fixed

1. **Empty or malformed collections crashed whole views (blank-screen DoS, ~25 render sites).** List consumers iterated server fields without checking they are arrays: `data.metrics`/`data.queues` (DashboardView chart and metric cards), `data.customers` (`.filter`/`.map`/`.length`), `data.cases` (KycView + provider-evidence feed), `data.alerts` (FraudView), `data.checks`/`data.statuses` (ChecksView), `data.tickets`/`data.statuses` (SupportView), `data.intents`/`data.statuses` (WithdrawalsView), `data.events` (AuditView), `data.reports` (ReportsView), `feed.cases` (ProviderEvidencePanel), `item.evidenceItems`/`item.checks`/`item.hypotheses`/`item.timeline`/`item.signals`/`item.messages`/`item.internalNotes`/`item.screening`/`item.relatedAlertIds`/`item.relatedCaseIds`/`record.requestedItems`/`record.receivedCallbacks`/`record.rejectedCallbacks`/`preview.policy.blockers`/`preview.evidence`/`report.sections`/`section.rows`/`table.columns`/`table.rows`/`subject.entries`. `ApprovalsView` is required to render, `data` approvals are required iteration input, and `item` approvalSteps are required entries — all iterated unvalidated input. Any non-array payload (object, string, number, null row) produced a render-time TypeError that took the operator screen down. Fixed by a new `src/app/server-fields.ts` module: `arrayOf`/`rowsOf`/`recordOf` normalize collections and records at the consumption site so a hostile row degrades to `"—"` in place while sibling rows keep rendering (pinned by `app-render.test.ts` render-to-string tests for every view).

2. **The required maker-checker pane crashed on an empty list.** `ApprovalsView` is required to render an empty queue, yet `useState` read the required `approvals` head and `selected.id`/`selected.subjectReference` dereferences ran unconditionally — an empty queue payload threw on mount. Fixed: `selected` now holds the required `ApprovalSummary` type or `undefined`, and the detail pane renders only behind `selected &&`.

3. **Foreign enum values fabricated message keys and bypassed option/label guards (~40 lookup sites).** Status/kind/role/priority/channel/author/decision fields were interpolated straight into `t(\`checks.status.${status}\`)`-style keys or indexed into maps: `subjectEntryLinks[kind]`, check statuses, ticket status/priority/channel/author, withdrawal status/role/decision, subject kinds, operator roles. A foreign value produced a fabricated label (the raw key itself) or `undefined.member` access; prototype members (`"constructor"`, `"toString"`, `"__proto__"`, `"hasOwnProperty"`, `"valueOf"`) resolved inherited properties — `subjectEntryLinks["toString"]` returned a truthy function, so a hostile kind rendered a bogus deep-link. Filter option lists offered raw server statuses including prototype members. Fixed: per-enum `…KeyOf`/`…Of` accessors in `server-fields.ts` whitelist exact members via `Object.hasOwn` on lookup records; `enumText` renders the localized label for known values and the raw string for foreign ones; `subjectEntryLinkOf` guards the link map; filter options pass through `checkStatusOf`/`ticketStatusOf`/`withdrawalStatusOf` before rendering.

4. **Unvalidated `tone` fields reached `data-tone` attributes.** Every badge used a raw server string (`"constructor"`, arbitrary class tokens) as `tone`/`data-tone`. Central fix: `Status` now routes `tone` through `toneOf` (five-value whitelist, neutral fallback), so hostile tones can no longer smuggle attributes or break badge styling.

5. **Missing/null nested record chains assumed presence.** `preview.policy.blockers`/`preview.command.digest`/`preview.auditAnchor.sequence|.hash`/`preview.evidence.ready|.total`, `data.chain.verified|.length|.headHash|.durable|.retentionDays`, `session.operator.displayName|.role`, `record.verification`/`record.outage`/`callback.verdict`, `entry.subjectReference`, report `period.from`/`.to` were read without presence checks — a partial envelope or aggregation degraded the pane. Fixed with `recordOf` + `textOf`/`truncatedOf`/`numberOf`/`intOf` fallbacks (`"—"`, clamped counts).

6. **Non-finite numerics rendered raw or produced NaN geometry.** `QueueChart` used `row.total`/`row.critical` as SVG coordinates and `count(row.total)` — `NaN`/`Infinity`/`"lots"` produced NaN coordinates and `NaN` labels; `preview.evidence.ready/total`, `chain.length`, `chain.retentionDays` and step-up `attempts` rendered raw non-numbers. Fixed: `countToward` clamps hostile counts to `0` (finite geometry), `safeCount`/`intOf`/`numberOf` degrade to `"—"`; step-up challenge `expiresAt`/`attempts` pass through `textOf`/`intOf` before `time()`.

7. **Unguarded string methods on server fields.** `entry.at.slice(0, 10)`, `record.providerReference.slice`, `preview.command.digest.slice`, `event.previousHash`/`hash.slice`, `value.toLocaleLowerCase()` and `.slice()`-style shortening were applied to values that could be objects/numbers — TypeError on render. Fixed: all call sites route through `textOf`/`truncatedOf` first; a source-grep test forbids `field.slice(`/unguarded lowercase on server receivers going forward.

8. **React keys and membership checks on raw server values.** Row keys used `step.id`/`event.id`/raw strings (duplicate or non-string ids corrupt reconciliation); `operator` `capabilities` are required to be an array yet `.includes(capability)` assumed one. Fixed: keys are suffixed with the row index; `capabilitiesOf(session?.operator)` normalizes the capability list once and every gate uses it (`mayPreview`/`mayStepUp` keep the same `capabilities.includes` call shape the a11y suite pins).

## Verified clean

- **Envelope verification (`data/client.ts` `verifyEnvelope`).** Strict on every axis a hostile payload could abuse: exact field set, canonical-JSON body, Ed25519 signature against operator keys, key `status`/`activeKeyId`, retired-key acceptance bounded by `issuedAt <= retiredAt`, resource match, `issuedAt` ISO-8601 plus a five-minute skew window. Unsigned error bodies surface as `ApiError`, never as verified payloads.
- **Money/decimal display.** Amount fields render the exact server decimal string via `textOf`; no `Number()`/`parseFloat` on `row.*`/`item.*`/`selected.*`/`metric.*`/`preview.*`/`customer.*` or the required `approval.*`/`decision.*` fields anywhere in the app (the existing i18n suite pins this and was updated to the `textOf` wrapper).
- **No markup/URL injection.** No `dangerouslySetInnerHTML`/`innerHTML` usage (pinned by the i18n suite); the only `href` is the static `/bff/auth/login`; no server-derived URLs, `window.open`, or `location` writes.
- **Date/time abuse.** `formatDate`/`formatTime`/`formatCount`/`formatLongDate` already fail closed to `"—"` on `NaN`/`Infinity`/Invalid Date; the new guards keep non-string timestamps out of `.slice`/`time()`/`date()` anyway.
- **i18n `translate` fallback.** Unknown keys render the key string — so `enumText` never passes a fabricated key (it only passes whitelisted `MessageKey`s and renders raw foreign text otherwise).
- **`import.meta.env`.** `runtime.ts` now reads `import.meta.env?.VITE_BACKOFFICE_MODE` so the module is safe to load outside Vite (test/runtime parity, no behavior change under Vite).
- **Dev-login role selector and navigation groups.** `t(\`role.${candidate.id}\`)`/`t(\`group.${group}\`)` interpolate only client-side constants (`roleProfiles`, `navigationGroups`), never server fields — intentionally left as-is and pinned by the narrower interpolation grep.

## Test additions

- `backoffice/src/app/server-fields.test.ts` (new): pins every guard in `server-fields.ts` — non-array collections degrade to `[]`, non-record rows are dropped, `textOf`/`truncatedOf`/`numberOf`/`intOf`/`countToward`/`toneOf` edges, prototype members (`__proto__`, `constructor`, `prototype`, `hasOwnProperty`, `toString`, `valueOf`) rejected by `subjectEntryLinkOf` and every enum accessor, full member coverage of each enum map — plus source-grep tests on `App.tsx` forbidding raw `data.X.map/.filter/.length`, `operator.capabilities` access, enum interpolation into `t(\`…\`)`, `subjectEntryLinks[` indexing, and unguarded `.slice(`/`.toLocaleLowerCase(` on server fields.
- `backoffice/src/app/app-render.test.ts` (new): renders every view/detail/widget to static markup under `I18nProvider` with hostile payloads — non-array collections, hostile row fields, foreign enums in details and filter selects, NaN queue counts, an empty maker-checker queue, malformed nested policy/chain/period objects — asserting no throw, degrade-in-place (`—`, sibling rows intact), and no fabricated message keys or `data-tone="constructor"`.
- `backoffice/package.json` `test` script and `backoffice/tsconfig.test.json` `include` updated to compile and run both suites (`react-dom/server` static render — no DOM needed); `i18n.test.ts`/`a11y.test.ts` source pins updated to the new guarded call shapes; verification-integrity baseline recomputed for touched files.
