# Dev-Stack E2E Arm Adversarial Audit — Wave 72 — Proposed

- Status: Proposed
- Scope: `packages/e2e-dev/tests/dev-stack.test.mjs` (the customer-journey and operator-journey arms through the miniapp and backoffice BFFs), `packages/e2e-dev/tests/boundaries.test.mjs` (startup-refusal boundary arm) and `packages/e2e-dev/tests/load.test.mjs` (bounded concurrent-load arm), plus the shared harness in `packages/e2e-dev/tests/stack.mjs`. Waves 70/71 (#332 chain arms, #337 OIDC arm) hardened the newest arms; these older journey arms predate the hardened harness. Everything is dev-only and synthetic — no production paths, no live data.
- Production effect: none

Hunt list applied: for every route a journey hits — does the arm assert the exact contract (status + error code + payload shape + value identity against the deterministic universe) or a weak proxy; are deny paths pinned or absent; are expected values re-derived independently of the product's own helpers; do boundaries cover every class; does the load arm pin response contracts under load or just completion; lifecycle hermetics; stale fixtures. Every defect below was proven green-arm on the mutated product before the fix landed; mutations were introduced only as proofs and reverted — no product change ships in this slice.

## Defects found and fixed

1. **Quote previews asserted numeric ranges, not the deterministic math.** The gated and verified preview assertions pinned `feeBps`/`spreadBps` presence and coarse ranges but not the exact decimals — mutating `feeBps`/`spreadBps` constants in `miniapp/src/server/quotes.ts` stayed green. The arm now pins every deterministic preview field literally (amountIn/fee/feeAsset/feeBps/spreadBps/netIn/total/insufficientBalance/kycRequired), bounds `rate.value` to the mid±25bps-jitter band around the 90 RUB/USDT synthetic reference, and recomputes `amountOut` from the returned price — a mutated mid/spread/fee breaks the band or the formula.
2. **`/bff/api/kyc` and `/bff/api/aml` payloads were length-only.** The journeys counted cases and read `providerEvidence` shallowly — a mutated `KYC-220184` status or a dropped evidence case stayed green (proven via `backoffice/src/data/demo.ts` mutation). The arm now `deepEqual`s the case arrays against `demoRepository.kycCases()`/`amlCases()` with literal spot-pins (KYC-220184 verified, AML-78041 High) and `deepEqual`s each provider-evidence entry's [id, linkedCaseId, scenario, providerStatus, projectedStatus, tone, verification tuple] plus the `operatorReview` contract per case.
3. **Backoffice deny bodies were unpinned or absent.** No request ever arrived unauthenticated at the backoffice BFF — swapping the 401 branch for 404 stayed green; `unsupported_role` had no body pin; the dev-session payload key-set could grow a stray member silently (proven each). New test pins `operator_session_required` on unauthenticated reads, `{error:"unsupported_role"}` on a bogus role, the exact `{authenticated, expiresAt}` payload key set and a safe-integer future expiry on every session mint.
4. **The gated wallet was under-pinned in both arms.** `assets`/`depositAddresses` could drift or mutate scales silently (proven: `synthetic.ts` `assets: []` mutation stayed green). Both journey sites and the load arm now `deepEqual` the full gated wallet literal — kyc/totalRub/availableRub/holdRub, the three assets at their exact scales, empty `depositAddresses`.
5. **Load-arm 200 bodies were unvalidated.** Status counts passed while response payloads carried stray keys or drifted (proven: `deposits.ts` gated-view stray key stayed green under load — re-proven red after the fix). The burst loop now pins the wallet key-set + gated literal, the per-kind degraded-view key set `{mode, kyc, listKey}` with gated ⇒ empty list, `{operations: []}` exact, checks-entry contracts (mode/direction/asset/executable/timeline ordering), the kyc-status contract-view fields, the kyc-submit application view, the report envelope's top-level field set + draft-report payload fields, notifications mode/delivery/unread/channel/delivered, screening 202 view fields + 429 `screening_rate_limited`, and activity `mode`.
6. **The operator/audit feed was unpinned.** Entries passed while `at`/`detailHash`/`action` drifted or froze (proven: `server.ts` `at: "1970-01-01"` literal stayed green). The arm now `deepEqual`s the first page entries against the live `demoRepository.auditSource()` slice mapped through the documented shape and pins `asOf` to the epoch literal plus `nextCursor: null`.
7. **Checks entries were status-length-only in dev-stack.** `reference`/`direction`/`asset`/`amount`/`fee`/`total`/timeline could drift — an `amount` mutation stayed green (proven). The journey now pins the five check tuples [reference, direction, status, asset] plus amount/fee/total decimals, `createdAt = now - createdAgoMs`, `expiresAt - createdAt = checkTtlMs`, the timeline statuses and `at` ordering, and the executable/reason contract per entry.
8. **Degraded collection views were field-level, not shape-pinned.** `mode`/`kyc`/empty-list checks passed with stray keys (proven: stray `bonus` key on the deposits gated view). All eight degraded list asserts in dev-stack and the new load-arm kind pins now `deepEqual` the exact `{mode:"test", kyc:"kyc-gated", listKey: []}` object.
9. **Error-body drift on 404/400/405 paths was unpinned.** `missing_route` mutation on the miniapp 404 branch stayed green; `invalid_request`/`method_not_allowed` bodies had no pins. Money-route 404s, the device-binding 400, the operation-detail 404 and every 405 now `deepEqual` the exact error envelope.
10. **Foreign-screening 403 body and capability gaps across operator roles were uncovered.** The foreign-subject screening-detail deny asserted status only — body `{error:"kyc_required"}` now pinned (foreign subjects are kyc-gated, so the KYC gate fires before owner checks). fraud-investigator/aml-investigator capability gaps (kyc/aml/reports/audit and reports/audit respectively) had no request coverage — a new test drives each denied GET through `deniedGet` pinning `capability_denied`.
11. **One lifecycle own-copy remained.** The miniapp server was closed via a hand-rolled `miniapp.close(cb)` instead of the hardened `closeServer` (SIGTERM/SIGKILL-aware) the rest of the suite uses — switched for parity with the #332 lifecycle classes.

## Verified clean

- **Lifecycle hermetics.** `stack.mjs` carries the #332 classes throughout: `stopService` SIGTERM→SIGKILL escalation, `startServiceOnFreePort` EADDRINUSE-only retry on port-0 probe races, `childEnvironment` env hygiene (PATH + explicit vars only), `runToExit` bounded waits — every service in the three arms starts/stops through them, and the only own-copy close was defect 11.
- **boundaries.test.mjs scope.** The arm pins startup refusals (bad tokens, malformed config values) rather than request-level boundary classes; charset/duplicate-key/oversized-body classes are covered at unit level (`backoffice server.test.ts`, `miniapp server.test.ts`), so the file's narrower scope is intentional, not a gap. No assertion-weak startup case found.
- **Stale fixtures.** Upstream-derived views (kyc/aml cases, audit feed, contract views under load) compare against the live demo repository/server output, not frozen literals, so a contract change turns the comparison red for the right reason rather than green on a stale copy.
- **Deny coverage — device binding.** `device_not_approved` is pinned in `operator-chain.test.mjs`, so its absence from this arm is coverage placement, not a hole.
- **Load-arm invariant pins.** Per-kind `(200+503) == total/24` with both sides >0, `{error:"domain_unavailable"}` 503 bodies per surface, screening `{202:cap, 429:rest}`, session-cap `{200:5, 401:55}`, customer-api `{200:40, 429:80}` + `Retry-After >= 1`, RSS < 320 MiB and runtime < 60 s all hold and were already exact.

## Observations (recorded, not defects in this slice)

- The provider-simulator jitters mid prices per call (±25 bps around the synthetic reference), so `rate.value`/`amountOut`/sell-side `fee` are time-dependent — the arm pins the mid±jitter band and the pricing formula rather than literals; multi-percent `SYNTHETIC_MID_PRICES` drift falls outside the band, while within-band jitter mutations are the simulator's own contract tests' job.
- `issuedAt` on previews is whole-second floored while `serverTime` carries the raw clock — both pinned separately after observing each precision.
- Session `expiresAt` is `now + 1800 s` raw; quote ids timestamp to seconds. The arm pins each at its observed precision.
- `/bff/operations` is the one degraded view without `mode`/`kyc` members — pinned as the exact `{operations: []}` shape.
- A foreign telegram subject is itself kyc-gated, so the screening-detail deny answers `kyc_required` (gate order), not an owner-deny shape — comment left on the pin.
